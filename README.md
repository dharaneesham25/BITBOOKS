PS09 – Campus Resource Booking System
Create a booking platform for campus resources such as classrooms, laboratories or other shared
facilities. Users should be able to view available resources and request a suitable date and time.
The system should check whether the requested resource is already booked before confirming a
reservation. Administrators should be able to manage resources and review bookings.
Core Requirements
• Administrators can add and manage campus resources.
• Students/faculty can view available resources and booking information.
• Users can submit booking requests with resource, date and time.
• The system should prevent conflicting bookings for the same resource and time.
• Users can view the status of their booking request.
• Administrators can approve, reject or manage bookings when approval is required.
• Completed or cancelled bookings should retain their status.
